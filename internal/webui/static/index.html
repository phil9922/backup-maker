            Backing up to another computer running backup-maker? That machine decides where the backups land, so set it up over there first: backup-maker receive enable --root <path> then backup-maker pair, which prints its device ID. Paste that ID here. That machine's own dashboard also shows the ID as a QR code you can scan with a phone, and backup-maker pair prints one in the terminal.

            Off by default: snapshots skip the same junk the live mirror skips. Tick this to seal a complete copy — useful for an archive you might restore years later, when a package may no longer be downloadable. It makes each snapshot much larger.

            There is no way to recover this password. Snapshots are AES-256 encrypted zips. If you lose it, they cannot be opened — by you or by anyone. Store it somewhere safe.
